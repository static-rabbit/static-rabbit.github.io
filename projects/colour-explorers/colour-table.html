Additional Information

  • Click on the Column visibility button to show/hide columns.
  • Columns:
    • Colour: Colour Name
    • Hex: Hexadecimal value
    • Description: Colour description, as returned by the Color Name API
    • Luminance: Measure to describe the perceived brightness of a color ("luminance, or visually perceived brightness")
    • luminanceWCAG: The relative brightness of any point in a colorspace, normalized to 0 for darkest black and 1 for lightest white
    • RGB: The rgb() functional notation expresses a color in the sRGB color space according to its red, green, and blue components. An optional alpha component represents the color's transparency.
    • HSL: The hsl() functional notation expresses a color in the sRGB color space according to its hue, saturation, and lightness components. An optional alpha component represents the color's transparency.
    • LAB: The lab() functional notation expresses a given color in the CIE L*a*b* color space. Lab represents the entire range of colors that humans can see by specifying the color's lightness, a red/green axis value, a blue/yellow axis value, and an optional alpha transparency value.
